# R9.26 — Public probe outcome checklist

This checklist was written after the bounded remote run was queued and before its responses were retrieved. Three new authored public cases contain obvious correctable faults. They stress the existing editing interface. They are not archived Groq drafts, a random corpus sample, an independent style test, or evidence of performance on already acceptable drafts.

The three conditions receive the same source and draft. The plain and anchored conditions also receive the same one-note content. Two repetitions use the exact same prompt and settings within each work/arm. Rotating and reversing the order uses all six within-work permutations across the six work-round blocks. Each repetition is a new request. It is not a new work.

Assess each completed output on the target repair, preservation of must-keep details, and visible new unsupported claims. An abstention or missing response is separate. Label a factual failure if a sentence visibly conflicts with these details. Leave ambiguous readings unresolved. Observe paragraph count, input and completion tokens, latency, and exact-repeat identity separately from semantic judgment.
