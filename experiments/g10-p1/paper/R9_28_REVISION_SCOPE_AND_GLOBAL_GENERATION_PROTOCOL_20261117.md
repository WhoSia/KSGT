# R9.28 — Selective sentence patching and source-guided document generation

Freeze both authored public cohorts and this protocol before the provider run. One repetition per input. Report results at work level. No external text or independent audience ratings.

## Revision cohort · 12 provider calls and six deterministic copy baselines

Three source works each have a clean and single-fault variant. Both model arms receive the same facts, original text, numbered sentences, task and priority to retain correct facts. Neither sees the planted target index or clean/faulty label. The whole-rewrite arm returns full prose with the option to copy unchanged. The patch arm returns KEEP or up to two single-sentence replace requests. The program applies structurally valid replacements atomically and copies unselected sentence bytes and paragraph delimiters. The mechanism comparison includes output encoding and permitted action space. It does not separately identify a prompting-only effect or all modes of substantive revision.

- Primary: restoration of the relevant proposition in a faulty draft, exact retention of clean draft, and faithful retention of all original source facts outside the planted proposition. Read source conformity separately from byte copying and report the number of selected sentences.
- R928_MAKERS: Friday 18:00 inclusive, first-time phone eligibility, receipt-message vs confirmed participation, bring material. R928_SHADE: a one-time reading at both spots, 34 vs 27, material unconfirmed, no air-temperature reading, no causal conclusion. R928_WINDOW: correct giver and recipient, unopened package, viewpoint, outside departure, rain after closing.
- Response parse failure is counted separately. Invalid patches produce no committed revision and are not equivalent to KEEP. Copy baseline has no provider token consumption. No retry on parse failure.

## Generation cohort · nine provider calls

Three new source works each receive the same facts and three-paragraph brief. Rich direct is a strong self-planning baseline. Linear outline adds the author plan. Reader-state adds three audience-specific cues to that same plan. These are author-supplied cues; automatic discovery and pure representation effects are outside the run. Report actual usage including input cost.

- R928_FIELD: strong booking scope, notification deadline vs trip, correct action of unnotified standby visitors.
- R928_POND: the numbers must read as same-day differences between two spots; distinguish observation from cause and unmeasured depth/current.
- R928_STATION: reader can track who hands and pockets the glove, preserve focal position, close on the departure, no unlicensed dialogue or knowing the glove's origin.

Review against source with opaque candidate IDs before joining conditions. Interpret individual density, transitions and endings only as provisional author-side observations. Ask the participating user about a narrow reader distinction only when a pair has comparable facts and a useful remaining ambiguity of flow.
