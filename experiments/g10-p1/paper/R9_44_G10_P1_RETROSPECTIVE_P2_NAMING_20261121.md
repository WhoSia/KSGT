# KSGT G10-P1 R9.44 — Full-stage retrospective, exit review and formal P2 naming proposal

**Research date:** 2026-11-21 KST. **Canonical stage:** G10-P1, OPEN. **P2:** proposed; NOT promoted. **Authority:** current stage record, Notion G10-P1 programme and individual R1–R9.43 reports, raw Drive custody records and executable GitHub code. This is a comprehensive research-director review and a reproducible reader-packet construction, not an additional unreported human evaluation or model improvement.

## 1. What G10-P1 originally promised

The official name is *KSGT Generation X G10-P1 — Lightweight Discourse-Guided Korean Prose Generation: Source-Conditioned Planning, Contextual Linguistic Realization & End-to-End Quality Evaluation*. [Canonical programme](../RESEARCH_PROGRAM.md) and [Notion G10-P1](https://app.notion.com/p/40def561cf9281a0b990ee1b3662b79e). Its causal question is whether a lightweight source-conditioned discourse and Korean-realization layer makes **complete reader-facing Korean writing** more usable than a **strong, same-model direct or rich-prompt reference**, at a defensible total compute and annotation cost. Existing semantic contracts, editing authority and linguistic formalism are supporting tools, not substitute endpoint metrics.

### Critical counting constraints

Historical 196 generated paragraphs, Global Document 001's 36 documents, R5–R8's 63 final texts, R9.14's 15 paragraphs, R9.23's 9 prose texts and later source-reused outputs must **not** be summed into a number of independent samples. The pre-existing `CURRENT_STAGE.json` retained `latest_experiment=R9.23` while the branch progressed through R9.43; historical counts can remain as historical counts, but the latest-work pointers must be separated from those cumulative records. All R9.34 source briefs are *exposed development* after use even if first created for a new-work pilot.

## 2. What did not survive refutation?

1. **Always provide an explicit discourse plan:** false as a default policy. On multiple development tasks, a strong direct/rich prompt matched or outperformed structured intervention on overall source-fidelity-sensitive criteria. Prefer conditional deployment when a specific reader-observable relation is at risk.
2. **A typed/validated plan guarantees truth:** false. Source-licensed units, references and even explicit conditional bindings did not stop fabricated actions, shifted deadlines and unsupported causal claims from appearing in the actual realization.
3. **More intervention or more calls are cheaper:** false on the tested budget. Staging and detect+repair regularly increased tokens; annotating the source costs additional human labor not included in model tokens.
4. **Zero-pronoun success is a proxy for good Korean:** false. Explicit naming remains appropriate in many single-actor situations, and the isolated OMIT decision contradicts the actual name-rich prose generator. The author-supplied 20/20 controller is not independent gold.
5. **Any unlicensed literary texture is an error:** too strong. A fixed-source test may ban new scene events but allow incidental details; future prose assessments must predeclare the license budget by genre.
6. **The project has become only a prompt comparison:** historically wrong but presently a real risk. P1 also contains executable discourse/reader state, exact source-linked relations, correction authority, code tests and provider custody. Its remaining scientific deficiency is *their impact on usable full Korean texts*.

## 3. P1 exit decision — keep OPEN, do not fabricate a win

**Passed as engineering/development:** code and live API; cross-model probes; original-byte preservation; independent reproducible receipt validators; narrow state operators with documented counterexamples; public-source revision probes; two-phase evaluation packet construction.

**Not passed as a full writing-quality claim:** independent Korean reader decisions or edit burden; calibrated independent source-fidelity annotation; source-work-disjoint confirmatory test; a model/compute-matched comparison showing positive end-to-end gains; total annotation and extraction costs.

An honest P1 exit can be either a bounded *pilot closure without superiority* after preserving these negative and null findings, or a completed prospective reader evaluation. Neither justifies silently declaring a generalized quality gain. **Do not set `current_stage=G10-P2` in this review.**

## 4. Proposed formal P2 name — proposal ONLY

**KSGT Generation X G10-P2 — Reader-State-Coupled Korean Writing Architecture: Source-Grounded Discourse Dynamics, Adaptive Realization & Human-Validated Quality–Cost Trade-offs**

**Scientific delta from P1:** Instead of assuming a planning prompt helps, execute a source-grounded reading-state transition **after each realized sentence**, distinguish extracting the state from using it, and test when to leave a satisfactory passage untouched. The architecture may use a general LLM as a candidate generator or later a genuinely small realizer, but the causal mechanism must be observable in full Korean writing.

**Executable interface:** `(source facts + author intent + reader model + realized prefix) -> candidate utterance -> state update / source-relationship evidence -> KEEP or bounded revision -> next utterance`. The reader-state estimator must be checked against actual Korean readers; merely applying a hand-written state is an upper-bound oracle.

**Required same-information comparisons:** strong direct single-call prose, strong rich instruction, same model with identical state serialized as ordinary prompt, state-driven controller with the same candidates, explicit plan without controller, and a compute-matched iterative drafting rival. Include a *sham state* and a *no-intervention* control to identify regression and unnecessary cost. The unit is a full source work, not a word or sentence.

**Evaluation:** initial complete-text reader phase without source fact list, independent later source audit with facts, preregistered work-disjoint test and equal-model budgets. Report source factuality, reader task success, pairwise usable-document choice, first edit location/effort, voice/naturalness, lexical diversity within author, total provider tokens, wall time, annotation labor and memory. Predeclare how literary scene texture differs from invented events.

**Lightweight architecture track:** only after end-to-end benefit survives strong baselines, compare matched small Transformer, explicit-reader-state proposer and a recurrent/SSM alternative under equal tokenizer, source data, train/test separation, parameter/computation budget and real latency. Do **not** advertise a Transformer replacement without a direct quality–compute Pareto improvement.

### Formal decision gates

- **G0:** seal the P1 retrospective, raw receipts, known contradictions and full outcome denominators.
- **G1:** independent Korean reader evaluation of existing R9.34 exposed development outputs. A pilot with at least 24 new work-disjoint briefs across chat, science, notices and narrative, plus multiple independent readers per work, is a separate prospective study; its sample size is a planning target rather than a power claim.
- **G2:** extract source relations with evidence spans (not human-curated oracle information), and measure false exclusions and uncertainty.
- **G3:** same-model, same-facts, same-state and compute-matched end-to-end complete-text tests; prefer conditional/no-op control when appropriate.
- **G4:** only then evaluate whether a smaller architecture gives a defensible quality/cost advantage.

**Suggested P1 disposition at handoff:** `G10-P1 OPEN — R9.44 EXIT REVIEW, P2 NAME PROPOSED, NO POSITIVE WRITING QUALITY CLAIM`. Scientific negative results are legitimate; the P2 proposal must not erase them.
