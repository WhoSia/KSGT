## 2. Key semantic and experimental separations
1. **Research unit:** source WORK, not sentence, candidate rendering, tool call or multiple annotator judgments. Distinct text SHA values cannot be considered independent genre observations.
2. **Measured outputs:** 196 historical single-paragraph cases; 36 separately reported global docs; historical R5–R8 75 provider *calls* and 63 final *texts*; R9.14 15 more real completions; 27/54 new authored *compositions*. These come from overlapping research streams and **cannot be summed into a deduplicated total**.
3. **Text identity versus semantic or quality agreement:** KoLLA 432/1410 is exact reference-string equality only. R8 identical output 2/6 is an identity tie, not either policy's victory.
4. **Prompt and cost:** R9.14 RICH_BASELINE totals 2728 provider tokens over three tasks, ORDER_PLUS_KOREAN 3612 (~32.4% greater), while the single native speaker felt the rich baseline better in the practical notice. This is exploratory evidence against blindly adding control text.
5. **Source authority:** false author intention, invented regular recurrence, made-up action, source recast as a reader-facing checklist, and omission of essential actionable information are distinct defects.
6. **Register:** politeness style was intentionally set aside in R9.14 science reading; a plain-form versus honorific comparison cannot support a grammatical realization effect unless register is controlled.
7. **Source fidelity:** an author-confirmed full-sentence variant may still imply a new presupposition or timeline. No string hash, copied fact IDs or regex flags can certify semantic equivalence.
8. **Preference aggregation:** reader judgments vary by *information economy, reading comfort, rhythm, event sequence, genre fit, factuality*; different dimensions may conflict. Unanimity-only data admission risks typicality bias.
9. **Internal plan versus final prose:** a technically valid plan is a hidden computation representation. The final reader should not see factual compliance commentary like `정확히 보존되어 있습니다` unless actually relevant to a requested audit.
10. **Research novelty:** neither better RST outline nor compact-then-expand prompting alone yields meaningful Korean NLG novelty. The hard scientific question is whether reader-conditioned information-state representation induces reader-preferred, source-supported **prose** at a measured cost.

## 3. R9.22 concrete engineering — paragraph-history conditional variants
R9.21 conditioned a complete sentence on one preceding fact ID, but could redundantly restate `7일째` after the preceding sentence already said it. R9.22:
- Uses the **actual realized previous text** and bounded **last 1–3 source fact IDs**, not merely a prior fact label.
- Requires a full author-written expected-current exact sentence, full source-fact set match, exact supported surface style, and full approved replacement.
- Allows a source-admissible conditional variant only when all observations match. If multiple rules apply, **fail closed**, never arbitrarily pick by file order.
- Keeps two modes: `BASE` returns byte-for-byte R9.21 `BOUNDARY_ADAPTED` output; `CONTEXT_WINDOW` applies additional approved variants as appropriate.
- **Science example:** after a fact containing `7일째`, replace the redundant `7일째 관측만으로 원인은 단정할 수 없다...` with `이 차이의 원인은 단정할 수 없다...`, retaining unmeasured illumination/soil moisture. This is a manually authored contextual adaptation, not a learned pronoun/repetition detector.
- In the notice and scene, alternative full sentences can adapt an application deadline following equipment information and an explicitly licensed event sequence, respectively, only for author-prescribed conditions.
- Null quality claims, no Groq calls, no parameter training. A changed string or absence of a repeated cue does NOT establish increased naturalness.
