# KSGT R9.42 — Source-warranted actor competition

Freeze four synthetic Korean scenes and five contexts each: one actor; a competing actor; the competitor departing; an additional sentence that explicitly marks only the intended person remaining beside the relevant object; and that competitor returning. Hold the next action and its intended actor constant within each work. R9.41 assumed an exit permits omission. This assumption is too strong: leaving a room does not guarantee that the person ceases to be an accessible discourse subject.

The events are manually authored annotations. Require every event sentence to be found verbatim, uniquely and in order in the actual source prefix. Record the source offsets. A departure event by itself never removes the competing referent. Only a separately written exclusion sentence changes this finite inventory to one actor; a return reintroduces competition. Treat the result as an executable author convention, not an open Korean parser, a universally correct reader interpretation or an empirical preference for subject omission.

Offline reference: compare always-name, naive departure and evidence-gated state. Online matched reference: GPT-OSS 20B with the full context only, versus the identical context plus the calculated candidate list. Use the same model, system message, next action and intended actor in both arms. Output source action retention, overt-name frequency, original response, tokens and request/response hashes. The annotation must never supply a gold label, output sentence or a direct omission command to the model.

Predeclared limitations: the synthetic corpus and source annotations are designed by the investigator; the exclusion sentence is deliberately strong; correct candidate counts do not establish that actual readers understand the bare subject; the no-LLM policy excludes annotation labor. Hold-out prose and independent reader interpretation must precede any generalized gain claim. The next evaluation must also compare the same candidate list provided as a plain prompt against executable selection, rather than assuming control architecture is responsible for a benefit.
