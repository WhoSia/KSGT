# R9.39 — Detect, retain, or repair a paragraph locally

Freeze six matched pairs of authored two-sentence Korean drafts with source facts and the target relation held fixed. Six are clean. Four changed drafts have a missing or wrong second-sentence relation (two action scopes, two actor links). The two remaining changes occur in sentence one and cannot be fixed solely by changing sentence two under the brief's immutable-prefix contract. Three works are adapted from earlier examples; this is a controlled component test and not an estimate of real draft frequencies.

Compare retaining the input, a one-call full paragraph rewrite, and a classifier followed by a local generation call only for a REPAIR response. KEEP leaves the input untouched. HOLD leaves the input untouched and flags it for wider review. When the known later-disclosure literal already occurs in sentence one, override the classifier to HOLD. For proposed local results require a single returned line with the protected phrase and release phrase. This literal gate has no authority over factual or relation correctness. For both arms count invalid and unnecessary changes, semantic recovery, relation preservation, and actual model token usage. The investigator's relation and fact judgments are diagnostic and not independent reader assessments. Report raw detector responses separately from the overridden action. All generated variants used for comparison are retained.

The full-rewrite reference is supplied the same source and draft. It may rewrite sentence one and therefore has a different edit budget. Include separate findings on initially clean, locally fixable and first-line-defective drafts. Report cost as editing overhead only.
