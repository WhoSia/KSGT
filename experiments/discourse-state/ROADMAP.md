# KSGT — From reader-state transitions to Korean paragraph generation

The project goal is a small, controllable Korean generator that can produce materially different passages for different audiences and purposes while preserving the author's facts and voice. The generator should choose what a reader can learn at a point in the text, how that affects the following sentences, and when explicit wording is needed. The causal question is whether making those updates executable improves controllability, writing quality, or resource use over a model with the same evidence.
