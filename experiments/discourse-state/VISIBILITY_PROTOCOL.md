# R9.38 — Withholding a later fact from the first rendering call

Six short Korean briefs, three notices and three scenes, with two adapted from R9.37 and four new. All place one protected fact in sentence two. For each work, compare two staged conditions that use identical model settings and first-call prompts except the later fact field, either the actual fact or null. Call two receives the actual first output and identical source, constraints, and protected wording in both conditions. Differences mediated by the first generated text are part of the intended comparison. A transport-failed first output is not advanced. A content error does not disqualify the first line from continuation.

The single-call paragraph planner is a reference, not a matched causal condition. Score the exact disclosure marker in each line, complete formatting, protected phrase retention, and model usage separately. The author screens whether the two actions are the same actor's, or whether a notice's condition is explicitly scoped over both actions. Exact markers are only an operational check. Record scope uncertainty separately from verified correctness, and do not infer reader preference or Korean population prevalence from this pilot.
