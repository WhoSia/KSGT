**Copyright and provenance:** The StyleKQC HF dataset is tagged CC BY-SA 4.0 while the LREC paper metadata uses CC BY-NC 4.0; these are not necessarily the same artifact. Verify original dataset version, attribution obligations, and license at the specific source before downloading, modifying, or redistributing. The NIKL report is publicly readable but does **not** thereby authorize redistributing any missing dataset row bytes.
