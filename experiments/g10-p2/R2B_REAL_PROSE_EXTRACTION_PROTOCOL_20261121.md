# G10-P2 R2b — 원문 생성 뒤의 명제 승격 위험, 기존 완성문으로 비교

**사전 고정: 2026-11-21 / 새로운 모델 추출 호출 전 / P1 원본 재사용 / 신규 외부 독자 gold 없음.**

## R2의 천장효과와 R2b의 단위

R2는 연구자가 직접 쓴 짧은 문단 40개에서 이진 사실 단정 40/40(두 방식 모두), 세분화 상태 40/40을 기록했다. 부정·전언·질문 표지가 뚜렷했다. 다음에는 이미 보관되어 있는 **R9.34의 실제 GPT-OSS 20B 생성 완성문** 8개 출처 작업×3조건=24편을 가져와 같은 문장을 분석한다. 생성문은 2026-11-21 R9.34 원본 provider artifact 14650903417 (SHA-256 `f27a6d8fd23c4a3bec2fad70c41497d73f3d50d4f865b32bff156d0dbcfbf48b`). 원문은 GitHub에 커밋하지 않고 CI에서 읽기 전용으로 내려받아, 다운로드된 각 response SHA를 확인한다.

원본 12글감 중 chat/science/notice/scene에서 각각 두 글감을 선정했다. R9.34 글 전체와 원천 사실을 이미 연구책임자가 읽었고 이 선택도 사후이므로 **독립 확인 표본이 아니라 노출된 개발 스트레스 테스트**다.

## 검증할 8개 명제

- CHAT_CHECK: 그림 2 범례 두 색상은 아직 원본 데이터와 대조 중이다. (명시적 확정 정보)
- CHAT_REPLY: 회의에서 A안이 최종 채택되었다. (앞서 실험하기로 했다는 계획을 최종 결정으로 잘못 승격하는가)
- SCI_SCALE: 두 측정의 영점 오차가 실제로 동일했다. (조건문에만 있는 전제를 사실로 승격하는가; direct 본문은 서로 다른 문장 간 긴장이 있으므로 사전 불확실 표기)
- SCI_CARD: 재질 차이만으로 **이번** 물방울 퍼짐 차이가 결정되었다. (예상 결과·조건문과 이미 확인된 인과를 구분하는가)
- NOTICE_SETUP: 전기 연결을 신청한 팀은 팀명·소비 전력 메모를 가져와야 한다. (전시대 신청과 전기 연결 신청의 서로 다른 적용 기준)
- NOTICE_ROOM: 수요일 정확히 14시 면담 예약자는 1층 상담실로 간다. (표 형식과 목록 형식의 동일 적용 범위)
- LIT_SHADOW: 수빈이 접은 천을 **받은 뒤** 계단 아래로 내려갔다. (rich 글에서 윤해가 받았다는 앞 문장과 수빈이 받았다는 뒷 문장 공존; 지칭자 충돌)
- LIT_CUP: 컵 안에 따뜻한 차가 남아 있었다. (guided의 '남아 있는 듯' 비확정·비유와 사실 단정 구별; 사전 불확실 표기)

각 원본 글에 대해 **텍스트가 그 명제를 사실로 단정해 쓰는지**를 연구자 판단 YES/NO/INDETERMINATE로 미리 지정하고, 판단이 어려운 2편은 강제 정확도 계산에서 제외하되 전체 호출·비용·근거 위치·예측은 보고한다. 이 자료는 정답 판정의 독립성을 갖추지 못했으며, source-fidelity(그 명제가 원래 출처 사실인가)는 별개의 판정이다. SCI_SCALE 원본이 자기모순을 품으면 '명제가 단정됐는가' 자체도 복수 문장에 걸쳐 흔들릴 수 있다. LIT_SHADOW rich의 수빈 수령은 **원천에 없는 생성 오류**일 수 있어도 실제 표면 본문에는 단정으로 존재한다.

## 실험·증거

R2가 이미 사용한 BINARY/ATTRIBUTION **동일 system 지침을 변경하지 않는다.** GPT-OSS 20B, temperature 0, 같은 대상 명제와 **같은 기존 완성문**을 입력하고 조건 순서는 짝마다 번갈아 배치한다. 24편×2조건=48회 호출 예정. CI는 Actions 원본 artifact를 actions:read로 내려받고 저장소에 push하지 않는다. 실제 원본 해시, 각 prompt/response 해시, response completion 상태, 모델 토큰·지연, 근거가 본문 안에 유일한 연속 문자열인지 검증한다. 기존 문서가 Markdown 표를 포함하면 해당 전체 텍스트를 손대지 않고 모델에 준다.

**일차 분석:** 사전 YES/NO에 대한 두 분류 방식의 단정 정확도(불확실 2편은 별도); 단정을 지어낸 위험과 잘못 배제한 위험; 지칭/조건/행위자 충돌 사례. **이차 분석:** ATTRIBUTION 다섯 범주의 한계(조건/비유/내적 충돌을 별도 코드로 표현하지 못할 수 있음); 증거 문자열이 실제 있어도 의미를 보증하지 않는 실패.

R2b 자체가 독자의 실제 이해나 한국어 문장 품질을 측정하지 않는다. 원본 R9.34는 이미 출처 작업으로 학습에 노출된 개발자료이므로 새 홀드아웃이나 24개의 독립 자료라고 세지 않는다. 다음 R3 전역 생성 실험에는 새 출처 글감과 강한 동일 정보·동일 모델 비교, 독립 인간 평가가 필요하다.
