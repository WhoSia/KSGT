# R6i — Knowledge-state microgrammar with strong direct rival
2026-11-27 · G10-P2 OPEN / QUALITY_HOLD / RIGHTS_SCOPE_HOLD

R6h exposed a source-level ambiguity: `A 센서에서만 출력 변동 폭이 감소했다` can imply that B did not decrease, while the same fixture left B unknown. Keep R6h immutable. New input removes this ambiguity and distinguishes knowledge states T (confirmed decrease), F (confirmed non-decrease), U (decrease unknown). Idealized reliable observation assumption: T entails actual decrease, F entails actual non-decrease, U leaves both possible. This is not a noisy-sensor epistemology. Two sensors yield nine knowledge states and sixteen consistent knowledge/actual configurations.

An investigator-authored finite microgrammar assigns truth conditions to each generated status clause. Candidate meaning is intersection of clause meanings; admissible iff equal to the source's set of configurations. `only-world` A actually decreases, B actually does not; `only-confirmed` A confirmed decrease, B not confirmed decrease (F or U). For TU, only-world is unsound and only-confirmed is sound but insufficient to recover U. World exclusivity alone cannot recover the knowledge state even when it happens to be true. This is a formal candidate-semantics result, conditional on manually assigned readings, not a Korean semantic parser or universal semantics of 만. Initial 54 candidates/42 exact; corrected awkward repeated topics and potentially ambiguous grouped subject, added 12 fused contrast candidates; 66 candidates/54 exact, 12 rejected, all nine complete paragraphs selected by shortest codepoint length among exact candidates. The selected strings remain developer-authored grammar output; shortest is not the same as naturalest. No training or external source data. Four semantic and two runner tests.

Direct rival: nine actual calls to the same 120B provider, each on the exact facts used by the finite realizer, with explicit natural Korean instruction and clarification of observation vs nonmeasurement vs nondecrease; same scope and report genre. One call per state, temperature 0, max 1200, no retry, stop on incomplete; preserve normalized response receipts. The compiler incurs zero provider calls, but manual grammar development cost is not zero. Evaluate both full texts for all required knowledge states, correct subject, no unsupported claims, and compare Korean naturalness qualitatively. Direct model need not use identical wording and may outperform the finite realizer stylistically. Report all nine, including failures; no independent annotators, no generalization to arbitrary prose or claims of semantic superiority without actual data.
