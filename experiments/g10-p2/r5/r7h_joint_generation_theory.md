# R7h — Shared computational context and world separation
Conceptual note after preregistration, before examining results. A joint request can share encoding of prefix and common source. The elementary entropy identity H(Y_1,Y_2|C)=H(Y_1|C)+H(Y_2|Y_1,C) suggests that correlated continuations may admit a shared representation, but the causal factorization in a decoder makes later continuations depend on earlier output and both source descriptions. This is not a guarantee of provider token savings or calibrated meaning. A useful architecture must maintain world-specific support sets W_i, not use their union as a shared source. Shared C should only be the common source intersection, with branch-specific constraints explicitly scoped. A branch cannot treat another branch's confirmed fact as its own knowledge. Since the actual decoder has joint prompt visibility, JSON keys alone cannot enforce that boundary. A failure can arise even with valid syntax. The experiment tests whether one call amortizes common prefix/context while preserving author-defined differences; it is a small synthetic development pilot, not evidence of universal efficiency or natural literary quality. A positive result would license an optional multi-alternative writer, not a mandatory architecture for a single requested text. A null/failure implies keep single-world generation and investigate isolation only if a real multi-alternative task justifies the extra work.
