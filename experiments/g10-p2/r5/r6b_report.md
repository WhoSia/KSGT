## A. Selection bias before model comparison
On 950 expression/sentence records, 924 uniquely linked to target forms. R6a original-witness extractor yields expert 744, model 4, joint 2. Actual replies demonstrate that the expert template explicitly quotes the complete source, whereas model answers often use a placeholder, short quote or angle-delimited terminal suggestion. Therefore comparing extraction counts as correction quality would be invalid. New symmetric terminal extractor requires one explicit recommendation, known conclusion or source-quoted replacement, terminal punctuation, no nested delimiter and minimum SequenceMatcher ratio. Direct conclusion path does not require complete source witness, so it can accept an incorrect or partial replacement; all outputs remain review candidates. ## B. Actual-text developer review, not human gold
Read five deterministically hash-ranked joint examples in each of EXACT, WHITESPACE_STRIPPED_EQUAL, DIFFERENT_SURFACE (15 total); inspected source, candidate and displayed portions of comments. Sample post hoc, not independent. Findings: (1) exact same revision can carry differing diagnostic categories (e.g. same role/capacity particle correction labelled orthography by expert versus particle error by model); (2) a whitespace-stripped match can conceal an additional spacing change unrelated to stated target, in either candidate; (3) a model can make the intended spelling correction and also change letter case unnecessarily; (4) two distinct repairs to redundant coordination can be grammatically plausible, so exact match is not a valid universal success criterion; (5) broad rewriting can repair syntax beyond the expert's targeted spelling change but changes interpretation risk; (6) an alternative full-form versus contracted-form choice may both be viable; (7) same diagnosis may yield new redundant postpositional construction in model output. Separately inspected the two jointly extracted old-rule disagreements and several expert-only examples; a model can diagnose one modifier attachment and then change a different attachment, and a revision can shift actor roles. These are developer observations; do not infer corpus-wide rates or certify expert errors. Examples paraphrased, no source passages retained in report.

## C. Shared operation projection and negative result
Reconstruct source->expert and source->model with SequenceMatcher opcodes (non-equal span/replacement triplets); exact reconstruction on all 530 paired cases. Intersect exact triplets and replay on source. Of 273 differing proposals, 151 unchanged, 103 equal expert, 6 equal model (changed), 13 distinct changed projection. Categories mutually exclusive, unchanged first. An intermediate nonexclusive tally double-counted 15 unchanged model suggestions; corrected. Shared operations often retain intended common spelling edit and remove unilateral collateral edits, but leave all problems when changes are disjoint, and shared errors can survive. Alignment choices can differ for equivalent edits. This is an oracle-assisted retrospective demonstration using both answers, NOT a deployable predictor or accuracy result. For an actual system use independently generated or norm-supported candidates and compare KEEP/direct/full rewrite at fixed information/cost; never provide expert target to a baseline-free runtime.

## D. Matched discourse diagnosis
On 89 paragraph and 100 document content/organization pairs, scan explicit action-word patterns (not semantic labels). Paragraph counts content/organization: evidence/detail addition 43/3, delete 1/12, split 8/3, order 0/2. Document: add 40/8, counterargument 53/0, split 0/25, merge 0/7, delete 2/6, order 0/1. Missing marker does not imply KEEP; matches can be negated, incidental or ambiguous; post hoc rules need manual validation. Read four deterministically ranked pairs per level from a topic-filtered development subset, full source and both expert comments (8 pairs). Actual examples: both roles may identify missing support, while one demands evidence and the other identifies logical connection; content can ask for empirical support while organization asks to remove an unsupported concluding expectation; both can praise the same writing with no concrete change; content can ask for extra evidence while organization requests moving the existing problem statement to the introduction; content and organization can both request stronger background, not disjoint labels; a single long paragraph can require both evidence additions and paragraph splitting. Content feedback can itself request structural changes (merge redundant evidence) and organization feedback can demand content addition. Therefore the architecture should represent edit intent as a set of potentially overlapping operations, not a single mutually exclusive feedback type. Missing evidence is a request to author/verify, not permission to fabricate facts. No quality certification.
