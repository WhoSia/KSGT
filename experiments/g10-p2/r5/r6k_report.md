# R6k — Temporal boundary of clause fusion: three sampled locations
2026-11-27 · G10-P2 OPEN / QUALITY_HOLD

R6j chooses clause fusion from a small manually labelled pool. A reference to an earlier state cannot license a claim that the state holds at a later event, and matching endpoints cannot license claims about the intervening state. To isolate this mechanism, three locations (window, door, desk) and three sample times (initial, middle, later book-opening event) form 27 finite trajectories. Source gives initial location and either later location or leaves it unspecified (12 configurations), plus three configurations with the same explicitly supplied initial/middle/event location (15). All texts share the same later book-opening event. This is a sampled discrete semantics, not continuous-time motion or universal Korean semantics; the meaning signature of each constructed text is manually supplied. Source unknown location means that the generated narration may leave location open, not an assertion of the narrator's epistemic uncertainty.

Five candidates per source: separate, coordinate, bare event (omits initial), assume same endpoint, assert all sampled locations same. Exact set equality between authored source and candidate conditions. 75 candidates, 36 exact, all 15 chosen exact; naive shortest 0/15 because every case has a deliberately incomplete bare-event competitor. This is a designed counterexample, not a fair natural-language quality baseline. If the initial and later locations are both window but the middle is unknown, three trajectories are possible; asserting the same middle eliminates two. If later location unknown, assuming same endpoint eliminates six of nine trajectories. Explicitly supplying all three samples licenses the anaphoric fused form, but not continuous presence between samples.

Initial receipt retained. On reading the first prose, noticed that '서 있었다' added posture not represented by the location-only source, and that '책을 펼쳤을 때' backgrounds the final action. Replaced with neutral '있었다' and an explicit event clause, with a unique location antecedent '그곳'. The finite counts do not change: this is an example of a semantic tag being insufficient to judge full prose. The location-state and common action assumptions are documented rather than pretending automatic linguistic interpretation. Four local tests pass.
