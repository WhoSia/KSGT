# R6t — Coupled reader-obligation presentation, one-call matched intervention
2026-11-27 · G10-P2 OPEN / QUALITY_HOLD / RIGHTS_SCOPE_HOLD

R6s showed that assigning a fact ID to a paragraph and selecting it as focus did not guarantee that the final prose realized its purpose. R6t tests a much smaller, single-call intervention rather than another model call or another mandatory decoder. Six newly authored synthetic briefs, 58 source facts, 16 intended paragraphs: lab report, friend message, limited-viewpoint fiction, essay, notice, argument. The first four reuse familiar failure *types* from R6r/s but not the same source; they are development examples, not an independent held-out corpus. No archives or restricted corpus text is sent.

Both arms get exactly the same system instruction, source facts, audience, task, paragraph count, paragraph-specific effect, new/previous source IDs. The user prompt's record multiset is exactly identical. DIRECT groups all facts first and all paragraph obligations afterward. COUPLED places each paragraph obligation immediately before its newly introduced facts. Previously introduced facts can be referred to in subsequent paragraphs; the original facts are not duplicated. These are authored reader objectives, not inferred or verified human reader states. This tests prompt layout/locality, not automatic planning or a claim that KSGT theory itself beats a baseline. The validator checks fact partition and backward references, not natural-language truth or reader effect. The direct arm is deliberately rich and contains the same intended effects; no weak generic baseline.

One GPT-OSS120B request per arm per work, alternating arm order, temperature 0, same max1600 token budget, no retries, stop on incomplete/provider failure and preserve partial receipts.
