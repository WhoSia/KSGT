## A — Exact edit lattice
530 jointly extracted R6b proposals for each role, 1060 source-target pairs. Unit cost codepoint insertion/deletion/substitution, equal codepoints cost zero. Suffix DP computes minimal distance and exact arbitrary-precision counts of optimal suffix paths. Forward prefix counts on the optimal-edge DAG identify an edit edge occurring on every minimum path iff prefix_count * suffix_count == total_paths. Edges are grid coordinates including target position; not linguistically normalized edits. Go and independent Python DP agree on distance, path counts, possible and forced edge lists for all 1060 pairs. 229 tiny/Unicode cases cross-checked by enumerating all paths (225 exhaustive strings of length 0–3 over two symbols, four extra fixtures). Both Go modes tested against reference and enumeration. Combining marks and decomposed Hangul are not normalized, grapheme segmentation not claimed. Go input assumes JSON Unicode scalar strings from trusted local loader; no general untrusted-service parser or invalid surrogate handling claimed.

Expert 110/530 ambiguous, model 178/530 ambiguous; changed proposals with no forced exact grid edit 89 and 77 respectively. Sum of exact unit distances 1145/2249 versus R6b SequenceMatcher proxy 1158/2285. This is not a quality comparison. Of 273 differing pairs, 175 have ambiguity on at least one side. Conservative projection of common forced replacement/deletion operations (excluding insertions entirely) leaves 176 unchanged, matches prior R6b projection in 235, matches expert in 81 and model in 20; last three counts may overlap. No semantic inference, uses expert outputs and cannot be deployed as an input-only predictor. This is a negative result against treating edit intersection as a reliable correction strategy. ## B — Algorithmic acceleration
An explicit feasible script preserves the longest common prefix and nonoverlapping suffix, substitutes the shorter residual and inserts/deletes the length difference. Its cost U=max(n,m)-prefix-suffix bounds the minimum. Every optimal path satisfies |i-j|<=U, since each insertion/deletion changes the offset by one and costs one. Store only rows of the resulting band. Time/cell memory O((n+1)*min(m+1,2U+1)) excluding big integer cost, versus O(nm) full grid; when U is large little benefit. Full-grid baseline retained via --full. Exact equivalence on 1060 actual + 229 tiny cases. Final full batch times (including JSON and subprocess overhead, excluding corpus parse and compile) Python 1.93237 s, Go full .97010 s, Go band .33384 s. Interleaved/reversed-order 3 repeats on every ninth proposal (118, both roles) median .243589/.114716/.036423 s. Single full execution and short sample benchmarks, not production latency or comparison with original SequenceMatcher. Initial slow dictionary-based reference attempt timed out, optimized Python arrays before final measurement. Initial sample stride 10 would select expert only; changed to 9. No Rust port or upstream fast-anything invocation.

## C — Intent-conditioned ordering

Same candidates and weights for greedy baseline. For state S, append a feasible unit x; incremental cost is sum of preference weights where x should follow a unit not yet placed. Exact minimum by DP; enumerate permutations independently as oracle. First seven development cases including deterministic searched greedy failure (23 vs 16 preference penalty) and a dependency cycle (no feasible plan). Round 1 conflated conceptual knowledge with introduced referent, allowing anaphoric opening even where reader only knows the concept. Round 2 distinguishes concept:sensor and referent:sensor in the annotations, and keeps evidenceAvailable separate from known/provided discourse tokens. The latter is explicitly supplied metadata, not a truth oracle. Knowledge-only case must still introduce referent; actual established referent permits first result. Required empirical evidence cannot be satisfied by asserting a token in a sentence or by assuming audience knowledge. Missing evidence returns REQUEST_EVIDENCE while preserving the existing sentences, not evidence generation. A library notice is reordered and science observation/limitation/plan rendered. No automatic semantic annotation, lexical rewriting, connector insertion, human rating, or causal same-model experiment. 10 authored cases and 200 deterministic small synthetic variants agree with brute-force minimum penalty; greedy counterexample remains. Hard constraints can overconstrain creative intentional ambiguity; human-specified tokens do not certify natural prose. O(2^n) states, <=16 units by design, not document-scale proof.
