# D19s / R6w candidate — Source-content budget, length pressure and expressive latitude

2026-11-27 · G10-P2 OPEN / QUALITY_HOLD / RIGHTS_SCOPE_HOLD. Development design, not stage promotion. No provider calls or independent human ratings.

## Explanandum and prior-art boundary
R6v report (eaf00a2bbaa45ebd6e4d1da7f90776bb53dbcb4a): only 1/4 cue-bearing works, and extra length did not establish quality. Distinguish content that must be communicated (core), available grounded optional material, and permitted non-factual elaboration. A longer text is not inherently better; a terse one can be difficult to understand. No universal claim that longer target causes invention.
Drive originals reconsulted: Hovy (1993), discourse purpose and reader knowledge, pp.341–385 (1JfrSoiB4AWHO7af-7USELbNl1edtyh-j); Moryossef et al. (2019), symbolic plan/neural realization on WebNLG (10a66yeNAm1JQuUuHQKkm2Yfvzc3TQcg8); Puduppully & Lapata (2021), paragraph macro-plans for sports summaries (1f0TdNKCafmg7ceeZZbxi8LgzO0Zl7Hvj); Lorandi & Belz (2026), level-playing-field controlled generation preprint (1MB-IhShSem5nTmC_nmMJx974JQoiB0Ez). These support conceptual ancestry and fairness constraints, not demonstrated transfer to Korean essays or fiction.

## Development design
Four new investigator-authored source families: science, notice, fiction, reflective essay. Within each family: 2 source richness (6 invariant mandatory facts vs same 6 + 6 optional facts) × 3 length targets (180–240 / 480–600 non-whitespace Unicode code points / flexible) × 2 expression licenses (strict vs bounded genre-specific expansion) = 12 cells, 48 total. Extra facts are optional in rich arms, not new mandatory obligations; the core is identical. Equal paragraph target (2), same model, system instruction, temperature, token ceiling and single call. Use full, strong genre-aware direct writing baseline in every cell; this is a factorial prompt intervention, not proof of KSGT architecture superiority. Prefer GPT-OSS120B temp0 and max2400 if authorized execution available. Randomize interleaved order with fixed seed in prospective run manifest. Do not retry silently; record all attempts, truncation and output hashes. Do not send private/NIKL corpus. Target lengths are investigator-selected exploratory bands, not normative or calibrated. All experimental sources are exposed development material; future confirmation must be source-disjoint.

## Outcome and comparison
Primary: source-core preservation (six distinct obligations, including explicit uncertainty/negation), count and kind of unsupported assertions, genre-license violations; independent source auditor not yet obtained. Separate reader utility, coherence, voice and first-edit burden via blinded assessment, including KEEP. Never score approved texture as invented fact merely because it is absent from brief. Distinguish licensed optional fact, entailed paraphrase, interpretive/uncertain statement, licensed elaboration, unsupported assertion, and indeterminate. Optional utilization and output length are secondary. Count Unicode code points after whitespace removal with no normalization of raw bytes. Record token cost, latency and completion status, not a scalar quality score.
Contrast long vs short within each family/richness/license; contrast richness within target/license; test whether the long-minus-short difference is moderated by richness or license. Report family-level effects individually, not 48 independent works. FLEX diagnoses task-driven natural length, not a randomized numerical dose. Length instruction assignment is causal treatment, achieved length is a post-treatment outcome; do not regress quality on achieved length as causal without additional assumptions. No independent human evaluation, inference or power claim until real outputs and independent sources. Genre-specific licenses differ in operation; do not pool effects as universal genre-independent law.
Rivals: stylistic padding unrelated to fact budget; richer briefs reduce ambiguity but increase competing material; source fidelity can improve with length when explanations require unpacking; license can increase legitimate variety without factual drift. Negative/null result leads to abandoning generic pressure correction, not metric proliferation. If strongest baseline handles every case adequately, do not mandate new architecture. Subsequent intervention must use same information and comparable compute.

## Implementation/verification
Manifest generated deterministically in a code-mode isolate. Eight explicit structural checks: 48 cells, unique IDs, core invariance, exact optional count, balanced per family, complete factor cells, fixed paragraphs, no generated output. These are design invariants only. No new live generation, no CI or quality claim. No native port; this is source/experimental design, not a compute bottleneck.
