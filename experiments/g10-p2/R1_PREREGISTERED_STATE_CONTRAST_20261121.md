# G10-P2 R1 — Post-realization state control preregistration, 2026-11-21

Test four newly authored short Korean source contexts across notice, chat, science, narrative. Each has two source claims and finite licensed Korean surface forms. The second claim offers an anaphoric realization licensed only after fact 1 is observed and a standalone explicit realization. Compare: faithful realized prefix, an unsupported/absent prefix, a quotation of the prefix, and replacing the earlier sentence. A plan-only policy that marks fact 1 known before checking the actual output provides a negative control.

**Expected engineering mechanism:** a real observer does not mark fact 1 known when the first sentence was omitted, changed, quoted or not licensed; it consequently selects an explicit second sentence. It selects the shorter anaphoric second sentence only when a recognized first sentence was actually written. A revision must invalidate/replay that evidence. Unknown output returns ABSTAIN rather than a fabricated correction; correctly licensed output returns KEEP with byte-exact identity.

Measure the number of full source witnesses admitted, rendered-line known states, rejection reasons, per-line output/source spans, state replay events and exact choice. All data are investigator-authored, fully exposed, finite grammar; 100% agreement with these fixture labels demonstrates only this narrow software contract, not Korean reader comprehension. No new Groq API calls or human reader outcomes in this R1 mechanism test. The next study must compare the same state serialized into a strong LLM's prompt, including a sham-state and cost-matched baseline.
