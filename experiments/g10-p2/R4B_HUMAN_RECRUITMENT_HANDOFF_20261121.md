# KSGT G10-P2 R4b — 사람 평가 운영·회수 지침 (2026-11-21)

**목표:** 모델의 국소 수정과 전체 재작성 결과 중 실제로 사용하기 좋은 한국어 글은 무엇인지, 그리고 원천 사실을 더 정확히 보존하는지 서로 다른 평가자로 확인한다. 현재 모든 실제 사람 응답은 **0건**이다.

## 평가자에게 무엇을 보낼까

- **A단계 독립 독자에게만:** [A 양식 4종 ZIP](https://drive.google.com/file/d/1EAskMB6CNFN2gIWG93C5oYjro52YdwcU/view). 작성 목적과 완성문 A/B만 제시하며 원천 원문은 공개하지 않는다. 사용 선호, 독해 질문, 최초 수정 위치를 기록하게 한다.
- **B단계 별도 원천 감사자에게만:** [B 양식 4종 ZIP](https://drive.google.com/file/d/1B86V5qG0VLwDu6g3zayjvVmRwuzC-WqM/view). 원천 사실과 글을 대조하고 원천 위반·조건 확대·행위자 오류·추가 사건을 인용 근거로 기록하게 한다.
- **연구책임자 보관:** Private method mapping은 Drive R4b 폴더에 별도로 저장했으며 A/B 어느 평가자에게도 전달하지 않는다.

## 배정·회수

각 ZIP에는 P1, P2, Q1, Q2 네 양식이 있다. 한 사람은 반드시 **한 양식만** 평가한다. P와 Q는 CHAT_UPLOAD·NOTICE_CHEM의 서로 다른 원본을 포함하고 SCI_SEED·SCENE_NOTE 출처는 반복되므로, A/B가 여러 평가자로부터 돌아와도 **독립 출처 글감은 네 건**뿐이다. 우선 최소한 각 양식당 한 명씩 **A단계 네 명, B단계 네 명**의 서로 다른 자발적 평가자로 탐색적 결과를 모으면 전 항목에 최소 한 번의 외부 의견을 받을 수 있다. 확증적 통계 검정이나 논문 근거로 보기에는 부족할 수 있어 필요하면 추가 평가자를 별도 배정한다.

완료한 MD 또는 PDF 양식은 원래 P1/P2/Q1/Q2와 A/B 구분을 유지해 회수한다. 파일에 사람의 실명·연락처 등 불필요한 개인정보를 적지 않고 예: A-P1-01처럼 익명 코드를 사용한다. 원본과 평가 날짜만 보존한다. 참가자에게 정답이나 모델명, R4a 자체 감사 결과를 먼저 공개하지 않는다. 한 사람이 A단계와 B단계를 모두 평가하지 않도록 분리한다.

## 실제 응답이 들어오면

1. 본문 전체의 사용 선호, 독해 정답, 최초 수정 위치를 **A단계**에서만 집계한다.
2. 원천 위반(새 장소, 새 약속, 사실 인과, 행위자, 사건)과 해당 F번호를 **B단계**에서만 집계한다.
3. 사전에 보존한 연구자용 조건 키로 A/B를 국소 수정 대 전체 재작성에 복원한다.
4. 표본의 실제 독립 단위가 네 글감임을 명시하고, 반복 양식·반복 독자를 독립 표본으로 더하지 않는다.
5. 실제 원본의 총 모델 토큰 8,147 대 8,839와 평가·주석 시간을 함께 보고하며, 확정적 우월성은 독립 복제 연구 전까지 보류한다.

## 현재 남은 사람의 일

**사람만 할 수 있는 일은 자발적 독립 독자·감사자에게 양식을 전달하고 응답을 회수하는 것**이다. 모델이 대신 답을 채우거나 연구책임자와 동일한 사람이 자기 사례를 심사하면 독립 평가로 인정하지 않는다. 연결된 Drive 자료는 현재 소유자 전용이므로 외부 평가자가 링크로 바로 열 수 있다는 가정도 하지 않는다. 외부 공유 권한 설정 또는 해당 ZIP 파일 직접 전송이 필요하다.
