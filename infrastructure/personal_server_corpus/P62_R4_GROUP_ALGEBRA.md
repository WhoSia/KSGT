# P62-R4: Conditional Evidential Group Algebra (CEGA) — Theory Note v0.1

## Formal object and boundary

Consider a mechanically observed Korean numeral-group surface witness, parsed as a provisional component record G_i with a counter type and integer n_i. The parser does not thereby prove that the witness denotes any actual set of people, animals or discourse entities. The following theorem is deliberately **conditional on a finite-set interpretation of those witnesses**, compatible counting units, and intended coordination as mathematical set union.

For two finite sets A and B with |A|=m and |B|=n, an unseen overlap x=|A intersection B| satisfies 0<=x<=min(m,n). Therefore max(m,n)<=|A union B|=m+n-x<=m+n. In general an observed coordination marker plus two numerical surface mentions cannot identify x, and cannot establish exact union cardinality. The overlap-neutral interval [max(m,n), m+n] is tight: examples with nested and disjoint finite sets attain its endpoints when the universe is sufficiently large. This is a mathematical conditional bound, NOT observed Korean discourse semantics.

The machine type for a coordinated union hypothesis stores: separate originally verified group witnesses; one originally verified coordination-marker witness; component identifiers; shared counter type; optional conditional bounds; unknown overlap; total_cardinality=NULL; reference_licensed=false. It never synthesizes a single denoting source span for a discontinuous union.

In a proposed group-selection countermodel, an explicit target-local requirement r greater than the *conditional* upper bound rules out the set interpretation **under its assumptions**. A requirement within the bounds does not license the referential link. If m=3,n=2, r=6 is conditionally impossible, r=4 depends on the unobserved overlap, and r=3 is not refuted; none demonstrates a correct real antecedent. Unknown cardinalities, mixed counters or unparsed requirements must HOLD.

## Algebraic operation

The abstract interval transformer J([L1,U1],[L2,U2])=[max(L1,L2),U1+U2] is an overlap-agnostic **lax bound composition**, not exact set union.

J is commutative and associative on nonnegative valid bound intervals. Its upper bound is not idempotent: J([3,3],[3,3])=[3,6], even if both expressions happened to denote the SAME actual set of three. Thus algebraic grouping of interval bounds can be stable without proving the semantic identity of nodes or the correct distribution of Korean conjunction. Treat duplicated mention identity as unresolved, not automatically disjoint.

Additional composition risks: noun phrase types may not share referential universes; coordination can be collective, distributive, disjunctive, elliptical, or rhetorical; explicitly distinct roles do not alone prove non-overlap. Surface-typed counter equality is necessary for this narrow comparison, not sufficient for real denotational compatibility. Negated, quoted and hypothetical mentions cannot become asserted actual-world entity sets solely through arithmetic.
