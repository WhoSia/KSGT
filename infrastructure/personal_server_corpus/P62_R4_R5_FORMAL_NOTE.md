# P62-R4-R5 formal and Korean-linguistic countermodels

This note is a source-only theory object. Korean sentences below are newly authored synthetic constructions, not corpus excerpts, human judgments, or claims of universal acceptability.

## Typed evidence and a custody invariant

Let an original structure provide a set of source-witnessed numeral nodes `S` and conditionally proposed coordinated unions `U`. Each node has a bounded original code-point span and a source-occurrence identity. Let `A(s)` mean that an independent admission gate verifies that span in the original source. Let `Q(s,t)` encode the existing quotation, assertion, counter and target-quantity constraints for target `t`. Descriptor equality `D(s,t)` and following-particle category equality `R(s,t)` are *surface predicates*. Neither is a semantic role relation. A valid new proposal policy may select only from `E(t) = {s in S : A(s) and Q(s,t)}` and must retain a separate `HOLD` when an admissible union in `U` competes under unresolved membership overlap.

**Custody proposition.** If a new policy only filters or ranks elements of `E(t)` and does not create a new source span, its selected span remains source admitted. The proof is immediate from set inclusion: a selected `s` belongs to `E(t)`, hence `A(s)`. This does not imply that `s` is a correct antecedent; admission verifies text custody, not discourse meaning. A coordinator span in `U` witnesses a relation in the text, while its members' intersection cardinality remains unobserved. The elementary finite-set bound `max(|A|,|B|) ≤ |A∪B| ≤ |A|+|B|` is classical, not a new Korean semantic theorem.

**Proposal nonmonotonicity.** Even when `D` or `R` is a subset filter on `E(t)`, proposal *frequency* need not be monotone. If two near groups cause a baseline abstention and a filter removes one, the filter can produce a new proposal. Conversely, filtering away the unique baseline choice can cause a loss. The frozen R5 role-proxy arm exhibited both directions: two proposal gains and 70 losses relative to guarded v3. One gain came from an unresolved coordinated-union HOLD, exposing a policy inconsistency rather than evidence of better reference. Development v2 restores that HOLD without changing source custody. Its one changed decision on the development split does not validate the semantic choice.

## Distinctions that the surface filter cannot establish

- **Changing syntactic position:** “학생 세 명이 왔다. 그중 두 명이 떠났다.” and “학생 세 명을 만났다. 그중 두 명이 떠났다.” are authored role-swap probes. A source subject and a source object can each remain plausible discourse groups when a later target is a subject. Exact case-category equality is therefore a deliberately falsifiable restriction, not a definition of co-reference. The naturalness and preferred antecedent of these authored examples have not been independently adjudicated.
- **Descriptor omission:** “학생 세 명이 왔다. 그중 두 명이 떠났다.” omits a repeated descriptor after the partitive target. An exact target/source descriptor gate must abstain even when a source group exists. The frozen court observed only 20 target-local descriptor surfaces among 281 targets and zero eligible exact matches; this is an instrument-coverage failure, not evidence that descriptor information is irrelevant to Korean discourse.
- **Group versus individual:** “학생 세 명과 교사 두 명이 왔다. 그중 두 명이 떠났다.” permits at least individual and coordinated-group computational hypotheses when membership and discourse focus are not fixed. A matched particle on one member cannot prove that a possible union is irrelevant. The source graph should keep conditional overlap and competing-group HOLDs explicit.
- **Quotation and negation:** A quoted group mention and a negated existence assertion require independent scope checks. A later quantity-boundary HOLD can mask an earlier invalid-quotation cause in a terminal status, so diagnostic evidence should be stage separated. Six previously exposed source-derived probes exhibit that masking; they are not six naturally observed reference judgments.

This note does not claim that grouping, case-marker matching, recency or salience features are new. [A Korean coreference heuristic study from the ACL Anthology](https://aclanthology.org/Y02-1005.pdf) already combined antecedent grouping with case-marker and recency cues; its own evaluation used a small labeled article set and cautioned that its heuristic weights were not general. [Kweon's 2011 original study](https://www.macrothink.org/journal/index.php/ijl/article/view/732) examined null versus overt pronoun interpretation in ambiguous Korean complex sentences and found different subject/object preferences in that task. Neither paper supplies ground truth for the present partitive target population. Their results make an unqualified “same particle means same referent” rule especially difficult to defend.

The next theoretical object should represent discourse entities and event roles separately, so an entity can persist while its grammatical role changes. It should test role-swap and descriptor-omission minimal pairs against simpler lexical/proximity mechanisms while carrying source custody and assertion scope as orthogonal proof obligations. This remains a P62 research question. It is not P63 closure evidence.
